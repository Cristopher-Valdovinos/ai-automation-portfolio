# AI & Automation Portfolio

Proyectos de inteligencia artificial aplicada, automatización y APIs. Cada carpeta es un proyecto independiente, con su propio README, pruebas e instrucciones para ejecutarlo.

[![tests](https://github.com/Cristopher-Valdovinos/ai-automation-portfolio/actions/workflows/tests.yml/badge.svg)](https://github.com/Cristopher-Valdovinos/ai-automation-portfolio/actions/workflows/tests.yml)

## Proyectos

| Proyecto | Descripción | Tecnologías |
|----------|-------------|-------------|
| [llm-text-api](./llm-text-api) | API REST para resumir, clasificar y extraer datos de texto con un modelo de lenguaje local | Python, FastAPI, Ollama, Docker, pytest |

Cada proyecto incluye también una explicación sin tecnicismos: [LLM Text API en simple](./llm-text-api/GUIA.md).

## Enfoque

- **Modelos locales:** los proyectos usan modelos servidos por Ollama, sin enviar datos a servicios externos.
- **Listos para ejecutar:** cada proyecto incluye Docker y variables de entorno documentadas.
- **Con pruebas:** las pruebas corren automáticamente en cada cambio con GitHub Actions.
